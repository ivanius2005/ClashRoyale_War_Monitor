# Fuentes del PDF

Se incluyen para que el PDF salga igual en cualquier máquina:

- **DejaVu Sans Condensed** (normal y negrita): licencia libre de DejaVu (derivada de Bitstream Vera). https://dejavu-fonts.github.io/License.html
- **Poppins** (Bold y Medium): SIL Open Font License 1.1. https://github.com/itfoundry/Poppins

Los símbolos raros de algunos nombres (☢, ⭐, シ, 亗, coreano…) se toman de las fuentes del
sistema si están instaladas. En la Raspberry: `sudo apt install fonts-dejavu fonts-freefont-ttf fonts-ipafont-gothic fonts-wqy-zenhei`.
